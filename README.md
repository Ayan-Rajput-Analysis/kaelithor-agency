## 🚀 Getting Started

### Prerequisites

- Node.js `v18.18+` or `v20+`
- npm `v10+`

### Installation

```bash
# Clone the repository
git clone https://github.com/Ayan-Rajput-Analysis/kaelithor-agency.git
cd kaelithor-agency

# Install dependencies
npm install
```

### Development

```bash
# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Quality Assurance & Typecheck

```bash
# Run TypeScript compilation check
npm run typecheck

# Run Next.js production build
npm run build
```

### Production

```bash
# Start production server
npm run start
```

## 🌐 Deployment

### Vercel (Recommended)

1. Push your repository to GitHub.
2. Import the project into [Vercel](https://vercel.com).
3. Framework preset will automatically detect **Next.js**.
4. Deploy!

Optional environment variables:
- `NEXT_PUBLIC_FORM_ENDPOINT`: Custom form handling endpoint (defaults to FormSubmit AJAX delivery to `kaelithor.agency@gmail.com`).
